## Coursework Overview

This repository contains my Programming for Cyber Security Coursework 1 portfolio.

The coursework covers Python programming concepts and software development practices introduced during Weeks 1–6 of the module.

The portfolio contains five programming exercises. Each exercise is implemented in Python, documented in its own README file and maintained in a separate GitHub branch.

## List of Exercises

### Task 1 – Security Tool

**Branch:** `security-tool`

- Develops a basic menu-driven security application.
- Requires user authentication before accessing the security menu.
- Includes a security event counter.
- Includes a brute-force password simulation.
- Includes login authentication with a maximum of three failed attempts.
- Provides an exit option.

### Task 2 – Security Event Logger

**Branch:** `security-event-logger`

- Develops a basic security event logging program.
- Requests a username and password.
- Records failed login attempts.
- Records successful login attempts.
- Displays event information, including event IDs and timestamps.

### Task 3 – IP Address Validator

**Branch:** `ip-address-validator`

- Creates a function called `validate_ip()`.
- Uses string operations to check IP address formatting.
- Checks that an IP address contains exactly three dots.
- Checks that there are four numerical octets.
- Checks that each octet is between 0 and 255.
- Returns True or False depending on the validation result.

### Task 4 – Security Incident Manager

**Branch:** `security-incident-manager`

- Uses Python dictionaries to store security incident information.
- Stores usernames, IP addresses, event types and risk levels.
- Adds and updates dictionary values.
- Removes dictionary entries.
- Displays all remaining keys and values.
- Counts the total number of dictionary entries.

### Task 5 – Reusable Cyber Security Utilities

**Branch:** `cyber-security-utilities`

- Creates a reusable Python module called `security_tools.py`.
- Implements password validation.
- Implements basic IP address validation.
- Generates strong random passwords.
- Uses a separate `main.py` file to import and execute the functions.
